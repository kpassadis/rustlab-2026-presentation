01 • Foundational Philosophy

Declarative + Engine = Computation

A model is not a computer program—it is a pure declarative representation capturing how variables interact. Separating policy (what to compute) from mechanism (how to run it) eliminates 6-month enterprise release sprints.

02 • Compiler & Memory Architecture

4-Stage Lifecycle & Zero-Allocation Arena

From raw nom parser combinators to a single contiguous Vec<f64> slab sliced via faer::MatRef / MatMut with zero heap churn on the hot loop.

01 • INGEST nom

Parse & Build AST

Zero-copy parser combinators transform definition.dsl into GraphAst and GraphDefinition.

02 • VERIFY petgraph

Static Invariants

DFS cycle detection, single-component connectivity check, port arity contracts, and state-transition shape matching.

03 • LOWER BufferLayout

Shape & Arena Layout

Propagates dimensions forward and allocates static offsets inside one contiguous Vec<f64> arena.

04 • RUN Algorithm

Zero-Copy Kernels

Disjoint unsafe raw-slice projection into faer matrix views (C = A × B) with zero runtime allocations.
